# Session End

A short checklist to close out a work session.

1. Run `npm lint && npm test` and confirm both pass.
2. If you made a non-obvious decision, add a record to
   [.agents/memory/decisions/](../memory/decisions/) using the next sequential
   number, e.g. `0001-slug.md`.
3. If you learned something worth remembering for next time, add a dated note
   to [.agents/memory/learnings/](../memory/learnings/), e.g. `2026-08-14.md`.
