# Session Start

A short checklist any agent should run through at the start of a work
session, before making changes.

1. Read [AGENTS.md](../../AGENTS.md) for the current project state.
2. Check [.agents/memory/decisions/](../memory/decisions/) for any ADRs
   relevant to the area you're about to touch.
3. Check [.agents/memory/learnings/](../memory/learnings/) for recent notes
   from prior sessions.
4. Confirm the dev environment is up: `npm run dev`.
