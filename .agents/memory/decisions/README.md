# Decision Records (ADRs)

Empty for now. When a non-obvious architectural decision is made, add a file
here named `NNNN-slug.md` (e.g. `0001-refresh-token-rotation.md`) so any
agent — Claude, Codex, Gemini, or Copilot — can check prior rationale instead
of re-litigating it in a future session.

## Suggested template
```markdown
# 0001: Title of the decision

## Context
What problem prompted this decision?

## Decision
What was decided?

## Consequences
What trade-offs does this create?
```
